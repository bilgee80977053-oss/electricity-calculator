# Цахилгааны төлбөрийн апп — UX v2

## Хуучин дэлгэцээс хийсэн өөрчлөлт

| Асуудал | Шийдэл |
|---|---|
| Chrome дээр форм дэлгэц даяар сунан харагдсан | Контентын `maxWidth: 1120`, төвд байрласан |
| Мэдээлэл босоо урт баганад байсан | 750px-аас өргөн үед форм, үр дүн/тариф хоёр багана |
| Нийт төлбөр харагдах дараалал сул | Том тоо, тайлбартай төлбөрийн карт |
| Тарифын тайлбар ганц мөрт шахагдсан | Гурван шатлал бүхий тусдаа карт |
| Үр дүн гарахаас өмнө хоосон том талбай | Icon, заавартай хоосон төлөв |
| Хөх gradient хэт давамгай | Ногоон–хөх palette, цагаан карт, зөөлөн сүүдэр |

## Өнгөний палитр

- Deep navy: `#183B4E`
- Emerald primary: `#087E74`
- Hero dark: `#123B4D`
- App background: `#F4F7F6`
- Card/background: `#FFFFFF`
- Soft mint: `#E5F4F0`

Тооцооллын логик, тариф болон validation өөрчлөгдөөгүй. Тестэд `ElectricityApp`-ын эхний төлөв, 220 кВт·цагийн тооцооллыг нэмсэн.

**Нотолгоо:** `ux_v2_preview.svg` нь загварын урьдчилсан дүрслэл бөгөөд бодит Flutter screenshot биш. Бодит харагдах байдлыг Windows дээр `flutter run -d chrome` ажиллуулж шалгана.
