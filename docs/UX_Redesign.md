# UX шийдэл — Smart Electricity Calculator

**F.CSM317 · А.Билэгсайхан · B242270028 · 2026-11-23**

## Одоогийн интерфейс

Энэ файл нь эхний загварын архив биш, GitHub дахь одоогийн Flutter хувилбарын UI-г тайлбарлана.

- **Responsive layout:** Өргөн дэлгэц дээр оролт, үр дүн/тарифын картууд зэрэгцэнэ. Гар утасны дэлгэц дээр нэг багана руу шилжинэ.
- **Харагдац:** Ногоон/цайвар палитр, цагаан карт, дугуйруулсан хүрээ, уншихад ялгарах нийт дүн.
- **Оролт:** Өдөр, орой, шөнийн өмнөх ба одоогийн заалт; хоосон, сөрөг, буурсан заалтын алдааны мэдэгдэл.
- **Үр дүн:** Тооцоолсон төлбөр, хэрэглээний задаргаа, дэлгэрэнгүй хуудас.
- **Хэл:** Монгол, English сонголт; өгөгдөл хадгалах.
- **Эх код:** GitHub repository руу нээх товч.

## Хөдөлгөөнт дүрслэлийн шийдэл

| Техник | Зорилго |
|---|---|
| `AnimatedContainer`, `AnimatedAlign`, `AnimatedPositioned` | Байрлал, төлөв өөрчлөгдөхөд хөдөлгөөнтэй харуулах |
| `AnimatedOpacity` | Элементийг алгуур харуулах/нуух |
| `TweenAnimationBuilder<double>` | Нийт төлбөрийн дүнг аажмаар харуулах |
| `AnimationController`, `CurvedAnimation`, `SpringSimulation` | Хэрэглэгчийн үйлдлийн хөдөлгөөнт хариу |
| `Hero` | Тооцооллын дүнгээс дэлгэрэнгүй рүү нэгдэх хөдөлгөөн |

## Загварын гол шийдвэр

Тарифын нарийн логикийг виджет дотор давтан бичихгүйгээр `lib/bill_calculator.dart`-д төвлөрүүлсэн. `lib/main.dart` нь оролт, харагдац, хэл болон хөдөлгөөнт эффектүүдийг удирдана.

Өмнөх UX v2 тайлбарт байсан хуучин палитр, батлагдаагүй preview зургийг энэ тайлбарт ашиглаагүй. **Хамгийн сүүлийн бодит UI-г** [Flutter web хувилбараас](https://bilgee80977053-oss.github.io/electricity-calculator/) үзнэ. Шинэ screenshot оруулах бол ажиллаж буй аппыг шууд авч, `docs/` хавтсанд байрлуулах ёстой.
