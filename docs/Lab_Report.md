## 4. Тооцооллын алгоритм

Хугацаа тус бүрийн хэрэглээ:

```text
Хэрэглээ = Одоогийн заалт − Өмнөх заалт
Нийт хэрэглээ = Өдөр + Орой + Шөнө
```

### 4.1. Гурван хугацаат тарифын загвар

| Нийт хэрэглээний шатлал | Өдөр (₮/кВт·ц) | Орой (₮/кВт·ц) | Шөнө (₮/кВт·ц) |
|---|---:|---:|---:|
| 0–150 кВт·ц | 179 | 294 | 119 |
| 150–300 кВт·ц | 200 | 305 | 119 |
| 300-аас дээш | 231 | 315 | 119 |

**Суурь төлбөр:** 3,360 ₮. **НӨАТ:** сонголттой, 10%.

Кодын хэрэгжилтэд нийт хэрэглээг эхний 150, дараагийн 150, үлдсэн хэрэглээ гэсэн шатлалд хуваагаад, шатлал бүрийн хэрэглээг өдөр/орой/шөнийн нийт хэрэглээний эзлэх хувиар тараадаг. Энэ нь **сургалтын тооцооллын таамаглал** бөгөөд хангагчийн баталгаажсан бодит нэхэмжлэхийн аргачлал гэж үзэхгүй.

**Жишээ:** Өдөр 220 кВт·ц, орой/шөнө 0 кВт·ц хэрэглэсэн, НӨАТ тооцоогүй бол:

```text
150 × 179 + 70 × 200 + 3360 = 44,210 ₮
```

### 4.2. Сургалтын тариф

| Шатлал | Нэгж үнэ |
|---|---:|
| Эхний 150 кВт·ц | 175 ₮ |
| Дараагийн 150 кВт·ц | 256 ₮ |
| 300 кВт·цаас дээш | 285 ₮ |

**Жишээ:** 1200-аас 1420 болсон тоолуурын заалт 220 кВт·ц хэрэглээтэй. Энэ горимын нийт төлбөр:

```text
150 × 175 + 70 × 256 = 44,170 ₮
```

Энэ горимд суурь төлбөр болон НӨАТ нэмэхгүй.

## 6. Лекц №13 — Animation хэрэглээ

Flutter-ийн implicit болон explicit хөдөлгөөнт дүрслэлийг дараах байдлаар ашигласан:

| Техник | Хэрэглээ |
|---|---|
| `AnimatedContainer`, `AnimatedAlign`, `AnimatedPositioned` | UI элементүүдийн хэмжээ, байрлалын шилжилт |
| `AnimatedOpacity` | Гарч ирэх болон алга болох эффект |
| `TweenAnimationBuilder<double>` | Төлбөрийн дүнг өсгөн харуулах |
| `AnimationController`, `CurvedAnimation` | Удирдлагатай хөдөлгөөнт эффект |
| `SpringSimulation`, `ScaleTransition` | Физик загвартай, масштаб өөрчлөх хөдөлгөөн |
| `Hero` | Үр дүнгээс дэлгэрэнгүй хуудас руу шилжих хөдөлгөөн |

Animation-уудын зорилго нь хөдөлгөөн нэмэхээс гадна хэрэглэгчийн үйлдэлд харагдах хариу өгөх, тооцооны үр дүнг ялгаруулах, дэлгэрэнгүй хуудасны шилжилтийг ойлгомжтой болгох юм.
