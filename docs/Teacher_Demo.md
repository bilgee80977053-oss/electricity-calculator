## Үзүүлэх дараалал

1. Багшийн утасны камераар **аппын холбоосын QR**-ийг уншуулна (эсвэл дээрх аппын URL-ийг нээнэ). Апп браузерт ачаалж байгааг шалгана.
2. Өмнөх өдрийн заалт 1200, одоогийн заалт 1420, орой/шөнийн хэрэглээ 0 нөхцөлөөр тооцоолно. Даалгаврын гурван хугацаат горимд НӨАТ-гүй **44,210 ₮** гарах ёстой.
3. **«Дэлгэрэнгүй харах»** товчоор Hero Animation бүхий дэлгэрэнгүй хуудас руу орж, буцаж үзүүлнэ.
4. **English** хэл сонгож, өмнөх оруулсан заалт, дүн хадгалагдаж байгааг харуулна.
5. Сургалтын тарифыг сонгож 220 кВт·ц хэрэглээнд **44,170 ₮** гарч байгааг үзүүлнэ.
6. Апп дахь эх кодын товчийг дарж GitHub repository-д шилжинэ. `lib/main.dart`, `lib/bill_calculator.dart` болон `test/` файлуудын үүргийг тайлбарлана.

## Багш асуувал товч тайлбарлах зүйл

- **Яагаад Flutter?** Нэг Dart кодын суурьтайгаар гар утас болон web хэрэглэгчийн интерфейс хөгжүүлэх боломжтой.
- **Яагаад логикийг салгасан?** `bill_calculator.dart` нь тарифын алгоритмыг UI-аас тусгаарлаж unit test бичих боломж бүрдүүлдэг.
- **Animation юунд хэрэгтэй вэ?** Хэрэглэгчийн даралт, үр дүн, дэлгэц хоорондын шилжилтийг илүү ойлгомжтой болгоно.
- **Албан төлбөр мөн үү?** Үгүй. Тариф, шатлалын аргачлал нь сургалтын өгөгдөл/таамаглал бөгөөд албан нэхэмжлэх гэж үзэхгүй.
