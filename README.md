- `test/widget_test.dart` нь `ElectricityApp` нэртэй зөв widget тест тул `flutter create .`-ийн үүсгэдэг default `MyApp` алдаанаас сэргийлнэ.

## Даалгавар

Зургийн «Программчлалын даалгавар 1» — айл өрх/хэрэглэгчийн цахилгааны төлбөрийг тооцоолох апп: 1) дэлгэцийн зохиомж; 2) Flutter код.

## Ажиллуулах

VS Code-д энэ хавтсыг нээнэ. Flutter SDK суусан Windows PowerShell дээр:

```powershell
flutter create .
flutter pub get
flutter run -d chrome
```

Android emulator эсвэл утас холбосон бол `flutter run` ашиглана.

Тест:

```powershell
flutter test
flutter analyze
```

`flutter create .` нь платформын (`android`, `ios`, `web`, `windows`) стандарт файлуудыг шинээр үүсгэнэ. `lib/`, `test/`, `pubspec.yaml` нь өгөгдсөн төслийн үндсэн эх код юм. Хэрэв `flutter create .` өөрчлөлт хадгалах зөвшөөрөл асуувал эх файлыг нөөцлөөд үргэлжлүүлнэ.

## Тооцооллын горимууд

### Real Tariff (2026)

Даалгаварт заасан Дархан-Уулын өрхийн гурван хугацаат тарифыг НӨАТ-гүйгээр:

- 0–150 кВт·ц: өдөр 179, орой 294, шөнө 119 ₮/кВт·ц
- 151–300 кВт·ц: өдөр 200, орой 305, шөнө 119 ₮/кВт·ц
- 300-аас дээш: өдөр 231, орой 315, шөнө 119 ₮/кВт·ц
- Сарын суурь төлбөр: 3,360 ₮; НӨАТ тооцох нь сонголттой (10%).

Тарифын мэдээллийн дэлгэцэд эх сурвалжийг даалгаврын өгсөн байдлаар ЭХЗХ-ны 2026.05.29-ний №350 тогтоолын Хавсралт 2 гэж тэмдэглэсэн. **Тогтоолын эхийг энэ ажлын явцад ЭХЗХ-ны албан сайтаас олж баталгаажуулж чадсангүй.** Тиймээс эдгээрийг өгөгдсөн тарифын утгууд гэж үзэх бөгөөд эх сурвалжийн бие даасан баталгаажуулалт гэж тайлбарлахгүй.

Сарын нийт хэрэглээг 150/150 кВт·цагийн шатлалд хувааж, шатлал тус бүрийн хэрэглээг өдөр/орой/шөнийн нийт хэрэглээний харьцаагаар хуваарилна. Энэ нь аппын **ил тод implementation assumption** юм. ЭХЗХ эсвэл хангагчийн албан ёсны шатлал хуваарилах арга олж баталгаажуулаагүй тул дүнг албан нэхэмжлэхтэй ижил гэж үзэж болохгүй. НӨАТ сонговол цахилгааны төлбөр ба суурь хураамжийн нийлбэрт 10% тооцох нь мөн тооцоолуурын таамаглал.

### Educational Tariff

Лабораторийн хувилбарын прогрессив шаталсан тариф хэвээр:

- Эхний 150 кВт·цаг × 175 ₮
- Дараагийн 150 кВт·цаг × 256 ₮
- 300-аас дээш хэрэглээ × 285 ₮

Жишээ: 220 кВт·цаг = `150 × 175 + 70 × 256 = 44,170 ₮`. Энэ горимд НӨАТ, суурь хураамж орохгүй.

## Тооцооллын код ба тест

`lib/bill_calculator.dart` нь хоёр тарифын горимын тооцоолол, оролтын баталгаажуулалтыг UI-аас тусад нь агуулна. `test/bill_calculator_test.dart` логик, шатлал, НӨАТ, буруу заалтыг шалгана; `test/widget_test.dart` хоёр горим, НӨАТ сонголт болон UI баталгаажуулалтыг шалгана.

## Ашигласан widget, Dart ойлголт

`MaterialApp`, `Scaffold`, `AppBar`, `Card`, `Form`, `TextFormField`, `TextEditingController`, `OutlinedButton`, `FilledButton`, `ListView`, `Row`, `Column`, `showModalBottomSheet`, `setState`, `InputFormatter`, тооцооллын тусдаа `BillCalculator` класс.

**Хязгаарлалт:** Энэхүү ажил бэлтгэсэн орчинд Flutter SDK суулгаагүй байсан тул `flutter analyze` болон `flutter test`-ийг энд ажиллуулж баталгаажуулж чадаагүй. Кодын логикийн жишиг тестийг `test/bill_calculator_test.dart`-д оруулсан.
# UX v3 — Soft avant-garde

Энэ хувилбар нь лаванда–нил ягаан gradient, зөөлөн булан, minimal харагдацтай.
Төлбөрийн дүн `AnimatedSwitcher` + `TweenAnimationBuilder`-ээр аажмаар гарна.
Тарифын мэдээллийг дарж дэлгэх/хураах боломжтой. Бодох логик өөрчлөгдөөгүй.

Төслийг ZIP-ээс задлаад `flutter create .` (шаардлагатай бол),
`flutter pub get`, `flutter test`, `flutter run -d chrome` гэж ажиллуулна.
